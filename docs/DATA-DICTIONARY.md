# 检测区间与复检

采样日期选择限量标准[start,end)，不使用报告出具日。同产品同残留项目在采样日须恰有一条有效标准，方法须在适用范围内。浓度统一mg/kg，ug/kg与ppb乘0.001，ppm等于mg/kg。检出限LOD必须大于0。

定量值以[value,value]记录，低于LOD的定量值拒绝。ND或<LOD以[0,LOD)记录，<后的数值必须等于报告LOD。区间上界≤限量为PASS，下界>限量为FAIL，其余UNCERTAIN。<0.01相对0.005限量为不确定，不能当零。

## 校准曲线与换版

仪器定量须同时留存三件原始证据：`signal`（原始信号）、`dilution`（稀释倍数）与`curve_id`/`curve_version`（当次定量所用曲线）。曲线登记于 `sample_data/curves.csv`，字段含斜率、截距、量程、检出限、最大稀释与有效期。

- 报告上的 `result` 是当次曲线与该报告自身稀释的换算结果，必须能由 `(signal-intercept)/slope*dilution` 精确复算，否则按 CONSTRAINT 隔离。
- 曲线适用性按项目、方法、报告日期与批准状态校验；跨项目、跨方法、过期或未批准曲线一律 CURVE 隔离。
- 信号反算值低于曲线检出限或超出曲线量程、稀释倍数超过曲线允许上限，按 RANGE 隔离。

## 换版后的定量依据

裁决基准日（`adjudication_date`）默认为本来源中最晚的报告日期，也可通过参数固定。基准日当天每个项目/方法须恰有一条批准曲线，否则该组无可用依据，记 UNCERTAIN / NO_VALID_BASIS。

对同一样本/项目组内的每条有效报告，用**当前曲线**重新定量，并**始终使用该报告自己记录的稀释倍数**；不得把复检的原液稀释套到初检的十倍稀释上。按复算结论分三种情形：

- 仅一条有效报告：采用该复算值，依据 SINGLE_VALID。
- 多条有效报告且复算结论一致：采用一致结论，依据 AGREE，区间取各复算值的包络。
- 多条有效报告但复算结论跨越限量：样本无单一浓度依据，判 UNCERTAIN / BASIS_CONFLICT。区间取各有效复算值的包络（下界=最小值，上界=最大值），不拼接某一报告的稀释与另一报告的量程，也不静默偏向较新的复检。两版曲线、两套信号与稀释倍数均原样留档。

`calculations` 与 `basis` 由同一份依据生成；样本判定、`reconcile.grades`（批次风险，FAIL>UNCERTAIN>PASS）与 `reconcile.seal_scope`（封存范围，非 PASS 批次整批封存）不得各自重算。

## 复检关联

复检relation指向原报告，必须同样本、同批次、同产品、同残留项目、同方法、同采样日，报告日严格更晚。引用环、悬空引用与异样本引用隔离。每样本/项目只允许一个原始报告根。同报告ID多个版本先选最高version；同一报告ID内并列结果矛盾拒绝。其他残留项目不因复检被覆盖。

## 幂等与中断恢复

运行幂等键由输入字节、参数、规则版本与曲线登记表摘要共同计算。同一来源再次提交返回同一 run_id，不新增样本结果、不改写既有证据。证据先完整序列化并做 SHA-256 校验后才落库；序列化或写入中断时事务回滚，保留旧版本。归档 CSV 与 conclusion.json 均携带原始信号、稀释记录、两版曲线、依据分组与封存范围。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。

同一报告ID的多个版本先选最高version，再构建复检引用链；历史版本留作采信证据，不重复参与最终项目判定。
