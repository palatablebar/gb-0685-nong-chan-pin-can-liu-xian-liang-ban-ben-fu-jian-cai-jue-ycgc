# 检测场景

## 常规换版

12个苹果样本分4批，每个样本初检P01为<0.01mg/kg，采样日标准限量0.005，因此不确定。次日同样本同方法复检0.004且LOD0.001，判为PASS并替代原报告。每样本P02为30ug/kg，超过0.02mg/kg，仍FAIL。最终24项目，12PASS、12FAIL，四批均FAIL。脏批额外含缺LOD、同版冲突、错列、空行与重复表头。

## 换版期间初检/复检分歧（curve_change.csv）

批次 B501 在批次处理中换曲线：S501 初检 00501 在旧曲线 P01-2026A 上以十倍稀释定量得 0.0045（PASS），晚到的复检 00502 在新曲线 P01-2026B 上以原液定量得 0.0051（FAIL），限量 0.005，两者恰好落在两侧。

裁决基准日取 2026-08-04，当前曲线为 P01-2026B。把两条原始信号都放到当前曲线、各用各自记录的稀释复算：00501 得 0.00041905×10=0.00419048（PASS），00502 得 0.0051（FAIL）。结论跨越限量，S501 无单一浓度依据，判 UNCERTAIN / BASIS_CONFLICT，区间 [0.00419048, 0.0051]。既不采用较新的复检、也不坚持旧曲线，两版曲线与两条稀释记录同时留档。

同批 S502（0.002）与 B502 的 S503（0.003）只有一条有效报告，按新曲线复算均 PASS。因此 B501 风险等级 UNCERTAIN、整批封存（风险来源 S501），B502 PASS 放行。样本判定、批次风险与封存范围来自同一份 `calculations`/`basis`。

把 `adjudication_date` 固定为 2026-08-02 时，当前曲线回到 P01-2026A；固定为 2027-06-01 时无批准曲线，三组均 UNCERTAIN / NO_VALID_BASIS，但原始信号与稀释记录不丢。
